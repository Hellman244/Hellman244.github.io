# Personal portfolio

Open `index.html` in a browser to view the portfolio. It is a standalone page with its styles included; no build step is required.

## Personalize it

- The portfolio is personalized for Hellman. Update the email and GitHub links in the Contact section if they change.
- Edit the copy in About, Interests, Projects, and Learning Journey so it reflects what you are actually doing.
- Keep project labels such as “Concept” or “In progress” until the work is ready to present as completed.
- The page uses Manrope and DM Mono from Google Fonts, with system fallbacks if the fonts are unavailable.

The layout adapts for mobile screens and respects reduced-motion preferences.
